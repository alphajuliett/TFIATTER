# TFI@TTER v0.3.5

## Nouveautés

- Sélecteur d’emojis pour les TFI@Ts et les réponses, avec insertion à la position du curseur.
- Recherche GIPHY dans le composer principal et dans les réponses.
- Affichage des GIF GIPHY comme médias dans le fil, les profils et les conversations de réponses.
- Références GIPHY persistées sous forme d’identifiant (`giphy:<id>`) : aucun fichier GIF GIPHY n’est copié dans le stockage local.
- Appels de recherche et de rendu GIPHY effectués directement par le navigateur.
- Attribution « Powered By GIPHY » dans le sélecteur.
- Aucune migration PostgreSQL nécessaire depuis v0.3.4.
