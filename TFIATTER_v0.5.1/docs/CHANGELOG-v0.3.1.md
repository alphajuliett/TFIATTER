# TFI@TTER v0.3.1

- Polling global toutes les 2 secondes (`2000 ms`).
- Fil d’actualité actualisé silencieusement.
- Badges Notifications et Messages actualisés toutes les 2 secondes.
- Page Notifications actualisée toutes les 2 secondes.
- Liste des conversations et conversation privée ouverte actualisées toutes les 2 secondes.
- Réponses d’un TFI@T actualisées automatiquement quand leur fenêtre est ouverte.
- Profil affiché et ses TFI@Ts actualisés automatiquement.
- Suggestions actualisées automatiquement.
- Panneau administrateur actualisé automatiquement lorsqu’il est ouvert.
- Préservation du brouillon, du focus et de la position de défilement des messages privés lors des mises à jour.
- Aucun cycle de polling ne peut chevaucher le précédent.
- Aucune migration PostgreSQL requise depuis la v0.3.
