# TFI@TTER v0.2.1

## Ajouts

- Création de comptes depuis le panneau administrateur.
- Certification/décertification de comptes officiels par les administrateurs.
- Coche bleue affichée à côté des noms certifiés dans le fil, les réponses, les suggestions et les profils.
- Statistique du nombre de comptes certifiés dans le panneau administrateur.
- Photo de profil téléversable par chaque utilisateur depuis l’édition du profil.
- Photo de profil optionnelle lors de la création d’un compte par un administrateur.
- Migration PostgreSQL `004_v021.sql`.

La certification et le rôle administrateur sont indépendants.
